# Provenance

The task runtime, shared CLI/MCP tools, adapter boundary and nested task panels were written for this repository. They do not copy or depend on the bundled pi-herdr-agents host.

The session-pinning plugin that was briefly copied here has been merged back into `../plugins/session-pins`, which is the single live copy.

The current Pi-specific coordinator remains in dotfiles. Its runtime records, private session transcripts, PR database, Git checkouts, credentials and personal configuration were not copied into this repository.

Public source publication is authorized by the owner. this repository contains no copied Herdr host code. No distribution license has been selected. Public visibility alone does not grant an open-source license. Any later reuse of the Herdr-derived host requires its license and attribution to be retained.
