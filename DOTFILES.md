## COMMANDS

```bash
jdot stow              # Stow all packages (skips .jdotignore entries)
jdot unstow [pkg]      # Unstow one package, or everything
jdot alias             # Regenerate shell + Finder aliases from folders.toml
jdot doctor            # Find broken symlinks under $HOME
jdot benchmark-shell   # zsh startup perf (-r N runs, -v verbose)
jdot digest             # Regenerate this file
```

## FOLDER ALIASES

## ANTI-PATTERNS

- Edit `~/.config/*` or `~/.pi/*` directly (changes lost on next `jdot stow`)
- Hand-edit `~/.config/jdot/aliases.zsh` (regenerated by `jdot alias`, not tracked)
- Hardcode paths (use `$HOME`, not `/Users/justin`)
- Commit `.jdotignore` (machine-local; edit `.jdotignore.example` for shared defaults)
